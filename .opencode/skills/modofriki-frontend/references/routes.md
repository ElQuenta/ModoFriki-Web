# Rutas de ModoFriki

| Ruta | Página | Descripción |
| --- | --- | --- |
| `/` | Home | Hero, continuar leyendo, novedades y rankings. |
| `/series` | Catálogo | Búsqueda, filtros y paginación. |
| `/series/:slug` | Detalle | Ficha, capítulos y comentarios. |
| `/read/:slug/:chapter` | Lector | Modo cascada/paginado y progreso. |
| `/genres` | Géneros | Géneros y tags. |
| `/rankings` | Rankings | Obras mejor valoradas. |
| `/favorites` | Favoritos | Biblioteca personal. |
| `/profile` | Perfil | Historial y preferencias. |
| `/login` | Login | Acceso demo. |
| `/register` | Registro | Registro demo. |
| `*` | 404 | Página no encontrada. |

El lector oculta el header y el footer para maximizar el área de lectura.
