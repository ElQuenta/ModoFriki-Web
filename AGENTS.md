# Equipo frontend de ModoFriki

Para cualquier tarea de frontend, selecciona el perfil especializado que mejor
corresponda y léelo antes de editar. Los perfiles son complementarios; una tarea
puede requerir más de uno si cubre sus responsabilidades.

- `modofriki-ui-ux`: pantallas, componentes, estilos, responsive y accesibilidad.
- `modofriki-integration`: contratos tipados, estado de datos, autenticación local
  y preparación de integraciones sin salir del alcance frontend.
- `modofriki-frontend-qa`: pruebas, regresiones, validación visual y verificación
  de build/lint.

Para trabajo transversal, aplica primero el perfil que implementa el cambio y
después `modofriki-frontend-qa` para revisarlo. Conserva las convenciones de
`.opencode/skills/modofriki-frontend` cuando estén disponibles.
